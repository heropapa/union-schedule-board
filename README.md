# 유니온물류 스케쥴 게시판

- 사이트: https://gleaming-mermaid-cc23e0.netlify.app  (야간 바로가기: `?g=night`, 주간: `?g=day`)
- `master`에 push하면 Netlify가 1분 안에 자동 배포합니다.
- 범위: 부산2·부산3 **주간** + 부산 **야간**.

## 구성
| 파일 | 내용 |
|---|---|
| `index.html` | 게시판 화면. 상단 `[주간 \| 야간]` 전환 (선택은 기기에 기억됨) |
| `day-data.js` | 주간 전체스케쥴(어드민) 데이터 (이름·라우트·휴무만) — **자동 생성, 직접 수정 금지** |
| `night-data.js` | 야간 근무표 데이터 — **자동 생성, 직접 수정 금지** |
| `tools/convert_day.py` | 주간 어드민 엑셀(유스프에서 뽑은 것) → `day-data.js` 변환 + 검증 |
| `tools/convert_night.py` | 야간 월별 엑셀 → `night-data.js` 변환 + 검증 |
| `tools/day_range.py` | 주간 시트 링크 → 기간(첫날~마지막날) 추출 |
| `source/` | 원본 엑셀 보관 (**git 제외** — 쿠팡 아이디·사업자번호가 들어 있어 공개 repo에 올리면 안 됨) |

## 주간 화면
위쪽 고정 버튼으로 두 가지 보기:
- **전체스케쥴(어드민)** — 쿠팡 어드민처럼 캠프별(부산2·부산3) 사람 × 요일, 한 주씩 ◀ ▶. 캠프별 하루 출근·휴무 인원.
  두 캠프에 등록된 사람은 출근이 많은 캠프에 한 번만(다른 캠프 라우트를 뛴 날은 칸에 캠프 표시).
  이번 주 데이터가 아직 없으면 노란 안내가 뜨고, 처음 열 때는 휴무백업표가 먼저 나옴.
- **휴무백업표** — 구글시트(웹에 게시)를 브라우저가 바로 불러와 4주를 위아래로 이어 붙여 보여줌 (백업휴무자 제외).
  시트를 고치면 몇 분 안에 반영. 불러오기가 안 되면 예전처럼 시트 화면을 그대로 띄움.
- 라우트는 `516C,516D` → `516CD` 처럼 줄여 표시.

## 업데이트
**주간 전체스케쥴(어드민) (매주)** — 유스프에서 어드민 업로드 엑셀을 뽑으면 그 파일을 `source/day/`에 넣고:
```
python tools/convert_day.py "source/day/*.xlsx"
git add day-data.js && git commit -m "주간 전체 스케쥴 갱신" && git push
```
- 같은 날짜가 여러 파일에 있으면 나중 파일(파일명 끝 숫자 = 내보낸 시각)이 그 날짜를 대체 → 수정본은 그냥 새로 넣으면 됨.
- 아이디·사업자등록번호는 읽지도 출력하지도 않음.

**주간 휴무백업표 (4주마다)** — 시트 하나 = 4주(일~토) 기간. 새 시트 링크를 받으면 기간을 뽑아 `index.html` 위쪽 `DAY_SHEETS`에 한 줄 추가, 가장 오래된 줄 삭제 (3개 유지):
```
python tools/day_range.py "<구글시트 웹에 게시 링크>"
```
→ `{ from: '2026-10-11', to: '2026-11-07', url: '...' }` 형태로 출력되고, 탭 이름은 `10/11~11/7`로 표시됩니다.
오늘 날짜가 들어있는 기간의 탭이 자동으로 열립니다.

**야간** — 새 월별 엑셀(+어드민 양식 zip)을 받으면:
```
python tools/convert_night.py 야간근무표_월별.xlsx 야간근무표_어드민양식.zip
git add night-data.js && git commit -m "야간 근무표 갱신" && git push
```
- 근무표·어드민의 날짜는 **PDD** 기준. 입차는 그 전날 저녁이라 게시판 머리글에 `입차 / PDD` 두 줄로 표시(각 줄 `31일 (토)` / 1일은 `11/1 (일)`)하고, '오늘'은 오늘 저녁 입차하는 칸(= PDD 내일).
- 공개 범위 제한: `--until YYYY-MM-DD`(PDD) 를 붙이면 그 날까지만 게시 (뒤는 아직 바뀔 수 있을 때). 지금 잘려 있으면 다시 돌릴 때도 `--until` 을 줘야 함 — 빠뜨리면 중단.
- 출력은 통째로 새로 만들어지므로 **이번 주가 포함된 파일**을 넣을 것 (필요하면 지난 파일도 같이, 여러 개 가능).
- 쿠팡 어드민 내보내기(`schedule-v2-….xlsx`)도 같이 넣을 수 있음: 월별과 겹치는 날은 대조, 월별에 없는 날(예: 월별 시작 전 주)은 어드민으로 채움. 1회전만 하는 날은 `708B(D1)`로 표시.
- 엑셀 오타·빈칸·요일 불일치·어드민 불일치·보여줄 기간 축소는 모두 **중단**됩니다. 사유가 출력되니 엑셀을 고친 뒤 다시 실행.
- 규칙·오류별 대처는 `tools/convert_night.py` 맨 위 설명 참고.
